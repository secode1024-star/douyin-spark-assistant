# 火花助手 0.2.0 测试说明

本版支持每个好友同时立即发送和定时发送。根据用户最后确认的范围，直接从聊天页读取已有会话；不要求导入从未聊天的互关好友。纯本地、MIT 开源，不增加服务器、收费和检查更新。

真实页面只读验证和本地模拟发送分别记录；本次没有向真实好友发送测试消息。

## 使用流程

1. 退出旧版托盘程序，再安装本版。升级前数据库自动备份；旧配置和历史保留，旧备注配置需重新选择明确身份的好友。
2. 点击“打开官网登录”，由本人完成官网登录及必要验证，关闭这次专用浏览器的全部窗口后等待核验。
3. 首次核验通过后自动读取聊天好友。查看人数、时间、完整／部分／失败状态；状态表示这次会话扫描，不代表全部关注或互关好友。
4. 在“好友与发送”页搜索好友，填写消息。可直接“立即发送”，也可开启每日定时。新读取的好友不会自动发送。
5. 勾选已有发送配置，再点“一键发送已选项目”。同一好友的不同配置各自独立。
6. 全局暂停会阻止所有发送。退出后仍未执行的手动批次需点击“继续未完成批次”；跨天跳过。

没有读到目标好友时，请先在抖音里手动发一条消息，再回来刷新。会话可能按需加载，未读取到不等于一定从未聊过。新导入好友不会自动启用任务。

## 每日发送规则

- 每条配置每天最多执行一次。手动发送提前执行该条当天任务，到定时时间不再重复。
- 关闭定时只关闭自动执行，仍可使用手动发送。
- 内容与目标在入队时确定；重试明确未提交的失败时仍使用原请求和原快照。
- 双击、重复提交和定时碰撞不会生成第二次当天执行。
- 可能已提交、待人工核对和网页已核对的记录禁止普通按钮重发。
- 提交前再次核对账号；实际发送事件还会检查收件会话、批准正文及北京时间日期。发现变化会阻止发送，可能已进入提交阶段的记录仍保守保留为待核对。
- 备注不是唯一身份。身份无法核实、没有可用的已有会话或不能准确打开私信时，该项停止。群聊不作为个人好友发送。
- 网页可见不等于手机收到或火花延续成功；当前未观察到稳定消息编号时，结果仍保守显示“待人工核对”。

## 安装与本地数据

Windows 安装包目标名为 `SparkAssistant-Setup-0.2.0-windows-x64.exe`，源码包为 `SparkAssistant-0.2.0-source.zip`，附 SHA256。安装到其他盘时仍使用末级名为 `SparkAssistant` 的目录，例如 `D:\SparkAssistant`。

本轮安装器的 26 项实际探针已通过：目录回调 10 项、目录与资源保留 8 项、自启命令归属 8 项。没有覆盖本机现有安装、快捷方式和自启动配置，因此本版完整安装／卸载流程及全新 Windows 环境尚未实测，不能用旧版的历史安装记录替代。

Windows 默认数据目录是 `%LOCALAPPDATA%\SparkAssistant`；macOS 是 `~/Library/Application Support/SparkAssistant`。数据库、浏览器资料和发送账本只保存在本机，不进入源码包。升级后的 v2 数据库请勿用旧版程序打开；回退前需退出软件并由用户自行恢复备份，避免丢失升级后的记录。

本轮不会给真实抖音好友发送测试消息。冻结程序和浏览器验收使用本机模拟页面与临时资料。
