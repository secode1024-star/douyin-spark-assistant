## 已修复的打包问题

- 0.1.1：安装向导的目录回调使用 NSIS `GetFullPathName`，目标目录尚不存在时会返回空值，导致安装按钮禁用。改为纯字符串检查目录名，保持输入路径不变并恢复临时寄存器。详见 [NSIS 指令文档](https://nsis.sourceforge.io/Reference/GetFullPathName)。共享真实回调的 10 项回归检查已通过，覆盖新目录、默认目录、中文空格、尾部反斜杠和非法路径；已接入 Windows CI。
- 0.1.1 完整重建后再次通过静默安装、运行中安装保护、已安装程序 UI/IPC/内置浏览器持久化、运行中卸载保护、正常卸载与注册项清理。安装包大小为 290,226,120 字节。
- 本轮图形向导的点击验证因桌面工具应用授权超时未完成；不能把目录回调测试等同于实际点击安装向导通过。
- 构建机 PATH 中的 Poppler ICU 与 Qt 使用的 Windows 系统 ICU 符号不兼容。构建采用清洁 PATH，并过滤错误的顶层 ICU；最终冻结程序验收通过。
- NSIS 显式使用 UTF-8 编译脚本，修正卸载字符串转义；安装/卸载通过命名 mutex 检查运行状态。
- Mac 浏览器不进入 PyInstaller 的逐文件 Mach-O 重写流程，改在 `.app` 完成后原样复制完整浏览器目录并重新签外层应用。
