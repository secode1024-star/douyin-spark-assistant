# 火花助手 0.1.2 测试说明

这次优先更新登录与发送链路，并重新生成 Windows 安装包。纯本地、MIT 开源，无服务器、收费或检查更新功能。

## 安装与登录

1. 从系统托盘退出旧版火花助手，再运行 `SparkAssistant-Setup-0.1.2-windows-x64.exe`。
2. 默认路径可直接使用；选择其他盘时仍需使用末级名为 `SparkAssistant` 的独立目录，例如 `D:\SparkAssistant`。任意目录名支持尚未实现。
3. 打开软件，确认版本为 0.1.2。点击“打开官网登录”，在抖音官网首页登录。
4. 完成后关闭本次专用浏览器的全部窗口和标签页，等待软件自动进入聊天页核验。保持登录窗口打开时，程序仍在等待，不会仅凭你关闭扫码弹层判断登录成功。
5. 如果已有任务，它们会先暂停。确认当前账号和好友备注后，点击“核对后继续”。旧任务不会因换号后读到同名备注就自动恢复。

旧版安装目录与用户数据目录不同。升级不清除任务或浏览器资料；原 CLI demo 的资料仍与桌面版分开。卸载默认也保留用户数据，并保留源码版或其他安装目录的自启配置。

## 发送测试与结果

- 先建立一条发给你选定测试好友的任务，时间设为当天几分钟后，内容自行填写。电脑保持开机、联网、未休眠。
- 一个好友备注无效或有草稿，只影响该条任务；其他好友继续运行。编辑某条任务时，其他任务也继续调度。
- 当前实际抖音页面能识别我方消息方向，但没有确认稳定消息编号。因此程序会执行一次发送、等待并刷新，然后保守标为“待人工核对”。**这不等于确定没发送。** 请在手机里检查，不要用新建同内容任务来自动重试。
- 已验证：只有对方同文、旧同文、缺少标识、刷新后消失等情况不会被误报为本次已核对成功；可能提交后的页面或存储异常不会自动再发。
- 输入框原有草稿不会被覆盖。程序填写后但尚未提交就失败时，只清除能确认仍属于本任务的文字；无法安全清除会提示你处理草稿。
